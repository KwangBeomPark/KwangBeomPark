## About Me

재무 운영 경험과 실무 자동화 역량을 결합하여 반복 업무를 줄이고, 보고 효율을 높이며, 팀 단위 생산성을 개선하는 경량 업무 도구를 만들고 있습니다.

제가 만드는 도구는 수작업 감소, 월말 결산 준비 시간 단축, 문서 검토 속도 개선, 비개발자도 사용할 수 있는 자동화 환경 구축에 초점을 둡니다.

## 공개 프로젝트

### [SwiftDeck](https://github.com/KwangBeomPark/SwiftDeck)

재무 관리자와 오피스 실무자를 위한 Windows 포터블 생산성 자동화 도구입니다.

**목적**

반복적인 폴더 이동, 프롬프트 실행, 텍스트 입력, 일상적인 사무 작업의 비효율을 줄이는 것입니다.

**주요 기능**

- 자주 사용하는 폴더 및 공유 경로 원클릭 이동
- 프롬프트 및 SQL 텍스트 자동화
- 표준 이메일, 보고 문구, 반복 문구용 Hotstring 지원
- 실무 단축키 중심의 Key Remap 기능
- `.ini` 설정 파일 공유를 통한 팀 단위 배포 및 표준화

### [ClipOCR-Pro](https://github.com/KwangBeomPark/ClipOCR-Pro)

화면 캡처, OCR, 선택 텍스트 번역, 이미지 처리 워크플로우를 지원하는 문서 검토용 포터블 업무 도구입니다.

**목적**

일상 업무에서 화면 캡처, 문서 비교, 선택 텍스트 번역, 이미지 번역, 정보 공유 과정을 더 빠르게 처리하는 것입니다.

**주요 기능**

- 빠른 화면 영역 캡처 및 항상 위에 표시되는 플로팅 참고 이미지
- 증빙 및 문서 검토를 위한 주석 표시 기능
- 선택 텍스트 번역 워크플로우
- 스캔 문서 및 외국어 첨부 파일을 위한 이미지 번역 지원
- 보고서와 이메일 작성을 위한 이미지 리사이즈, 복사, 저장, 재사용 워크플로우
