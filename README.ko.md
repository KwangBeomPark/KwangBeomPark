# 박광범

**재무 운영 관리자 | 업무 자동화 | AI 활용 생산성 도구 개발**

폴란드 바르샤바에서 근무하고 있습니다.

저는 회계, 채권관리, 영업관리 및 재무 운영 분야에서 실무 경험을 쌓아 왔으며, 반복 업무를 줄이고 팀 생산성을 높이기 위한 자동화 도구를 직접 개발하고 있습니다.

소프트웨어 개발 자체가 목적이 아니라, 실제 업무 문제를 해결하기 위한 수단으로 프로그래밍과 AI를 활용하는 데 관심이 있습니다.

---

## 주요 관심 분야

- 재무 운영(Finance Operations)
- 업무 프로세스 개선
- 사무 자동화
- AI 활용 생산성 향상
- 내부 업무 도구 개발
- 보고서 자동화

---

## 기술 스택

- Excel VBA

- OCR
- 번역 자동화
- GitHub
- AI 활용 개발

## 대표 프로젝트

### SwiftDeck

실무자의 반복 업무를 줄이기 위해 개발한 Windows 생산성 도구입니다.

주요 기능

- 폴더 및 프로그램 빠른 실행
- 키보드 중심 업무 처리
- 업무 자동화 지원
- 실무 환경 최적화

프로젝트:

https://github.com/KwangBeomPark/SwiftDeck

### ClipOCR-Pro

화면 캡처, OCR, 번역 기능을 통합한 생산성 도구입니다.

주요 기능

- 빠른 화면 캡처
- OCR 텍스트 추출
- 번역 지원
