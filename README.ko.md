## 업무 및 경력

**Finance Operations · Commercial Finance · Business Control · Process Improvement** 영역의 경험을 결합하여 실무 과제를 해결합니다. 회계, 채권관리, 영업관리, 수익성 분석, 경영 보고의 반복 업무를 이해하고 이를 데이터 정합성 및 프로세스 개선 과제로 연결합니다.

업무 문제를 먼저 정의하고 적절한 도구를 선택하는 방식을 중요하게 생각합니다. 아래 프로젝트는 직접 개발한 도구의 사례이며, 공개된 기능만으로 회사 전체 배포 실적이나 정량적 비용 절감 성과를 의미하지는 않습니다.

### 주요 전문 분야

- 데스크톱 업무 자동화 및 AI를 활용한 개발·검토

## 주요 공개 프로젝트

### [Data Refinery](https://github.com/KwangBeomPark/04_DataRefinery)
**재무 데이터 정제·통합·발행**

CSV/Excel 원본 데이터를 정제하고, 기간별 데이터를 누적·검증한 뒤 분석 가능한 산출물로 만드는 Windows 데스크톱 앱입니다.

- 유럽식 숫자 표기, 텍스트 인코딩 및 손상된 CSV 구조 복구
- 기간·건수·합계 검증 후 데이터셋 발행
- **Python, PySide6, DuckDB** 기반 집계 및 Excel/Power Query 연계
- 프로모션 규칙 표준화 및 일별 시계열 데이터 생성

### [Stepwise](https://github.com/KwangBeomPark/06_Stepwise)
**ERP 및 데스크톱 작업의 검증형 자동화**

레거시 ERP와 사내 업무화면에서 반복 입력을 지원하는 데이터 기반 자동화 도구입니다.

- Excel/CSV 행별 값을 화면 작업에 연결
- **Python, PySide6, OpenCV** 기반 작업 전후 화면 상태 확인
- 오류 발생 시 즉시 중단, 행별 실행 기록 및 재개 기능

### [SwiftDeck](https://github.com/KwangBeomPark/02_SwiftDeck)
**업무 자동화 커맨드 센터**

AutoHotkey v2를 활용한 폴더 바로가기, 프롬프트·SQL·텍스트 실행, 핫스트링, 단축키 및 포터블 설정 도구입니다.

### [ClipOCR-Pro](https://github.com/KwangBeomPark/01_ClipOCR-Pro)
**화면 캡처·OCR·번역**

AutoHotkey v2 기반 화면 캡처, 플로팅 참고 이미지, 주석, 로컬 OCR 및 번역 워크플로우 도구입니다.

### [FileOps Hub](https://github.com/KwangBeomPark/05_FileOperation)
**문서·파일 처리 자동화**

공유 파일 동기화, Office/PDF/EML 변환, OCR 기반 문서명 정리, 예약 실행 및 결과 보고 도구입니다.

### [EML Viewer](https://github.com/KwangBeomPark/07_eml-viewer)
**이메일 문서 검토**

`.eml`, Outlook `.msg` 파일을 열어 HTML 본문, 인라인 이미지, 첨부파일을 확인하고 본문을 번역할 수 있는 Windows 앱입니다.
