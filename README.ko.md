# 박광범

**재무 운영 관리자 | 업무 자동화 | AI 활용 생산성 도구 개발**

폴란드 바르샤바에서 근무하고 있습니다.

저는 재무 운영 실무를 기반으로 자동화, 프로그래밍, AI 활용 개발을 통해 실제 업무 프로세스의 비효율을 개선하는 데 집중하고 있습니다.

전통적인 소프트웨어 개발자가 되기 위한 목적보다는, 현업에서 반복적으로 발생하는 문제를 이해하고 이를 줄일 수 있는 실용적인 업무 도구를 만드는 데 강점이 있습니다.

---

## 전문 분야

- 재무 운영 관리
- 회계, 채권관리, 영업관리
- 업무 프로세스 개선
- 사무 업무 자동화
- 보고서 및 데이터 자동화
- AI 활용 생산성 도구 개발

## 기술 관심 분야

- Excel VBA
- AutoHotkey

- Windows 데스크톱 생산성 앱
- GitHub 및 버전 관리
- AI 활용 코딩 워크플로우

## 공개 프로젝트

### [SwiftDeck](https://github.com/KwangBeomPark/SwiftDeck)

일상적인 사무 업무에서 반복되는 폴더 이동, 프로그램 실행, 작업 전환을 줄이기 위해 만든 Windows 생산성 도구입니다.

**목적**

실무자가 자주 사용하는 폴더와 프로그램에 빠르게 접근하고, 반복적인 사무 작업을 줄이는 것입니다.

**주요 기능**

- 자주 사용하는 폴더 및 프로그램 빠른 실행
- 키보드 중심 업무 처리
- 실무 중심 업무 자동화 지원
- 실제 업무 흐름을 기반으로 설계

---

### [ClipOCR-Pro](https://github.com/KwangBeomPark/ClipOCR-Pro)

화면 캡처, OCR, 번역 기능을 결합한 업무 생산성 도구입니다.

**목적**

문서, 화면, 다국어 정보 처리 과정에서 캡처, 텍스트 추출, 번역, 공유 업무를 더 빠르게 처리하는 것입니다.

**주요 기능**

- 빠른 화면 캡처 워크플로우
- OCR 기반 텍스트 추출
- 번역 지원
- 문서 및 정보 공유 업무 효율화

---

## 업무 배경

현재 재무 부문에서 회계, 채권관리, 영업관리 영역의 운영을 담당하고 있습니다.

저의 접근 방식은 재무 실무 경험과 자동화 기술을 결합하여 업무 품질을 높이고, 수작업을 줄이며, 팀이 바로 사용할 수 있는 실용적인 도구를 만드는 것입니다.

---

## 업무 철학

기술은 일을 더 복잡하게 만드는 것이 아니라 더 단순하게 만들어야 합니다.

좋은 자동화는 가장 복잡한 솔루션이 아니라, 매일 반복되는 업무 시간을 줄이고 기존 업무 흐름에 자연스럽게 녹아드는 솔루션이라고 생각합니다.
